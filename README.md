# Fuzzy Logic - Credit Assessment

Proyek yang menerapkan **Fuzzy Logic** untuk melakukan penilaian/klasifikasi kredit (credit assessment) berdasarkan data nasabah.

## Isi Repository
- `Fawwaz_Rifat_Revista_Fuzzy_Logic.ipynb` — notebook implementasi sistem fuzzy logic untuk penilaian kredit.
- `kredit.csv` — dataset kredit yang digunakan dalam analisis.

## Metodologi
Notebook mencakup pendefinisian variabel linguistik dan fungsi keanggotaan (membership function), penyusunan basis aturan fuzzy (fuzzy rule base), proses fuzzifikasi-inferensi-defuzzifikasi, hingga interpretasi hasil penilaian kredit.

## Cara Menjalankan
1. Clone repository ini.
2. Pastikan library `scikit-fuzzy` (atau library fuzzy logic terkait) sudah terinstal.
3. Buka `Fawwaz_Rifat_Revista_Fuzzy_Logic.ipynb` di Jupyter Notebook.
4. Jalankan seluruh sel secara berurutan untuk mereproduksi hasil analisis.
